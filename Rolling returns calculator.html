Rolling Returns Calculator

Point-to-point returns depend entirely on the day you happened to invest. Rolling returns show every possible entry point at once, so you see how consistent — or lucky-dependent — a fund's performance really is.

Methodology inspired by M. Pattabiraman (freefincal)

1. Fund NAV data

Paste date,NAV rows (one per line) or upload a CSV. Dates can be YYYY-MM-DD, DD-MM-YYYY, or MM/DD/YYYY. No historical NAV data on hand? Load sample data to try the tool first.

2. Rolling window

Choose the holding period. Every date in your data becomes a hypothetical entry point held for exactly this long.
